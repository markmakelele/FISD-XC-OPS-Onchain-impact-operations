# FISD XC — 90-second Buildathon Demo

**0–10 seconds — State the job**

“Blockscout provides the evidence. FISD XC turns the activity into an explainable next investigative move.”

**10–25 seconds — Connect or use labelled demo**

Select a supported chain and paste a public wallet/contract address. If the API key is not configured, stay in simulation mode and explicitly say the records are simulated.

**25–40 seconds — Current Position**

Point to the selected source, sample metrics, impact field and transaction timescale. Select a signal and show the connected transaction detail.

**40–55 seconds — Next Best Move + Move Board**

Explain the recommendation and score. Compare the recommended action with the alternate move cards, including each expected effect. Emphasise that the UI does not execute an on-chain transaction.

**55–70 seconds — Full Workings**

Switch to Full Workings; inspect the score contributions, rule method, provider status and transaction data.

**70–82 seconds — Verify**

Open the selected transaction in Blockscout Explorer. Add a local review marker if useful, explaining that it is an operator note, not an on-chain attestation.

**82–90 seconds — State the boundary**

“FISD XC is an evidence-linked triage workflow. It helps decide what to inspect next; its score is a heuristic, not a fraud verdict.”
