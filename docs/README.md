# FISD XC Simple Preview

This folder is the static-only version for GitHub Pages. It runs in simulation mode and never claims to be connected to live Blockscout data. The **Simple / Full Workings** switch changes how much of the simulated model is visible; it does not activate API access.

For live data, deploy the full-stack app from the repository root using `render.yaml` and configure `BLOCKSCOUT_PRO_API_KEY` as a host secret.
