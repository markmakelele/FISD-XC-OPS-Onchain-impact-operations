03 / Hosting profiles
STATIC PREVIEW

Simple hosting

GitHub Pages serves the branded docs/ build. It is demo/simulation only; the live connection is disabled and no API key is needed.

  1. Deploy from branch main.
  2. Select /docs as the publishing folder.
  3. Open the page and toggle Simple / Full workings to inspect the model with simulated records.
WEB SERVICE + API

Full-stack hosting

Render runs the Node.js app and Blockscout API proxy in one service. The API key is held in environment secrets, never in client HTML.

  1. Deploy the root using render.yaml.
  2. Set BLOCKSCOUT_PRO_API_KEY.
  3. Use /api/health and connect a supported address.
